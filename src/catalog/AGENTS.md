# catalog

What Garnet knows about models it did not ship with: ids, context windows, media support and **prices**. Used to cost token usage when `model.pricing` is not configured, to suggest model ids in setup and `garnet providers add`, and by `garnet models`.

- One source for prices: OpenRouter's public list (`https://openrouter.ai/api/v1/models`, no key). It carries the native vendors' own rates (Anthropic, Google, OpenAI; checked against Anthropic's pricing page and third-party Gemini price pages) and cache prices, in one small response. Provider model *lists* come from the provider's own endpoint (`checkModel` in `cli/setup/checks.ts` returns the ids); this module only covers prices and limits.
- `catalogId(ref, name)` maps a Garnet model to the catalog id: Anthropic `claude-opus-4-5-20251101` → `anthropic/claude-opus-4.5`, Gemini `gemini-3.8-flash` → `google/gemini-3.8-flash` (only on Google's own host; a custom `baseUrl` is a gateway), `openai-compatible` on `api.openai.com` → `openai/<id>`, on `openrouter.ai` → the id as is. Anything else (local servers, other gateways) has no catalog id and its price is **unknown**, never a guess and never $0.
- Three states of the same data (`Catalog.source`): `snapshot` (`snapshot.json`, shipped with Garnet), `cache` (`<GARNET_HOME>/cache/models.json`, written by a successful refresh and used when newer than the snapshot) and `live` (just fetched). `loadCatalog` never touches the network, so starting Garnet stays offline; only `refreshCatalog` fetches, and only when the owner adds a provider, runs a checked setup or `garnet models`. A failed or implausible response (fewer than 20 models) never replaces the cache.
- Regenerate the snapshot with `npm run catalog:update` before a release and commit it; it is sorted and one model per line so diffs are reviewable.
- Long-prompt tiers (Claude Haiku 5.5 over 100k tokens, Gemini 2.5 Pro over 200k) are kept as `pricing.tiers`; `costOf` applies the highest tier a call's prompt exceeds, so costs and `budgets.dailyUsd` stay exact. `tiered: true` only drives the "higher for long prompts" note in the UI.
- `catalogPricing` keeps cache-**write** rates only for Anthropic, whose adapter reports cache writes; other providers' write fees (Gemini, OpenAI) are not billed per call and their adapters report no write count, which would make every call's cost unknown.
- Tests inject `fetch`; never call the network in `npm test`.
